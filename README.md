# Clicker Offline WebView (Android)

This is a minimal Android app that loads an offline HTML/CSS/JS clicker game from assets.

## Where the game lives
- `app/src/main/assets/index.html`
- `app/src/main/assets/style.css`
- `app/src/main/assets/game.js`

## Build in GitHub Actions
Go to **Actions** → run workflow → download the `clicker-apk` artifact.

## Build locally (optional)
Open the folder in Android Studio and press Run.
